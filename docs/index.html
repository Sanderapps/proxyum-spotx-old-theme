03 · LEIA COM ATENÇÃO

Avisos importantes

Estas informações ajudam a evitar surpresas durante o uso ou a remoção.

VERSÃO

Spotify antigo

Usa o Spotify 1.2.13.661 para manter o tema antigo.

ALTERAÇÕES

Atualizações bloqueadas

O SpotX altera o Spotify e bloqueia atualizações.

REMOÇÃO

Dados locais apagados

A remoção completa também apaga login, cache e preferências locais.

WINDOWS

Aviso do SmartScreen

O .exe não possui assinatura digital e o Windows pode mostrar um aviso do SmartScreen.

INDEPENDENTE

Projeto sem vínculo oficial
